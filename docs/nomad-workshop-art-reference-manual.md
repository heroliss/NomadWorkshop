# 游牧工坊整体参考图：手动生图

打开 [ChatGPT 网页](https://chatgpt.com/) 的新对话，复制下面的 A 提示词发送即可。官方仍支持在聊天中直接要求生成图片，具体可用性取决于账号方案和工作区设置；不需要先配置开发者 API Key。见 [官方生图说明](https://learn.chatgpt.com/docs/image-generation)。

建议一张一张生成。A 出图后，在同一对话依次发 B、C 的修改说明，便于维持相近的镜头和内容。三个方案都属于概念参考，不是 Unity 实机截图。

## A · 移动之家

```text
请生成一张 16:9 横版的 3D 游戏整体美术参考图。游戏叫《游牧工坊》，是一款居民生活与移动工坊经营游戏。风格是温暖的风格化废土：结构可信、适度夸张、细节克制，接近高质量独立游戏的实时 3D 渲染。

镜头从车头左前方约 40 度向下俯看，完整展示一辆六轮移动工坊及周围沙漠。车辆约占画面三分之二，开放甲板宽敞，可以清晰看见人物和通路。车壳奶油白，设备旧青绿色，少量橙色安全件，深色机械车架，大橡胶轮胎。表面有适量使用痕迹，整体整洁而有生活气息。

甲板上有横置净水箱、饮水台、小厨房、带隐私帘的卫生角、画架和驾驶台。三名穿实用工作服的成年居民分别驾驶、搬水和维修，用芥黄、青绿和鼠尾草绿区分服装。人物略风格化，约六至七头身，避免大头玩偶比例。

环境是金色沙丘、层叠砂岩、稀疏灌木和一条行车土路，车辆右侧有小型取水驿站。下午暖阳，柔和冷色阴影，清晰的接触阴影。少量帆布、木作、灯具和生活物件增加温度，但不遮挡甲板。保留设施的可拆部件、门轴和合理管线。

这是 A 方案“移动之家”。请强调舒适感、统一配色和玩法可读性。不要武器、军事标志、蒸汽朋克装饰、复杂杂物堆、巨大多层建筑车。不要景深虚化，不要海报式文字。可保留很小的游戏状态栏，但不要让 UI 遮挡主体。
```

## B · 荒野工程车

在 A 出图后发送：

```text
请以上一张为内容和镜头参考，另生成 B 方案“荒野工程车”。保持相近的构图、车辆大小、六轮底盘、三名居民、主要设施和沙漠驿站。改变艺术方向：车体更方正硬朗，奶油色与沙黄色模块化面板、深石墨结构框架、厚实的青绿机械设备，轮组和悬挂更明显，检修盖、储物柜和拖曳结构用途清楚。环境偏赤陶砂岩和浅金沙地，依然温暖明亮。细节密度适中，以可信的野外工程感为主，不要军事化，也不要堆满零碎机械装饰。其他主要内容保持一致，便于比较整体风格。
```

## C · 游牧拼装工坊

随后发送：

```text
请以上面的内容和镜头为参考，另生成 C 方案“游牧拼装工坊”。保持相近的构图、车辆大小、六轮底盘、三名居民、主要设施和沙漠驿站。改变艺术方向：车辆由不同年代的零件经过精心维护拼装而成，轮廓略不对称，奶油色、旧玉绿色、陶土红和沙色帆布统一成组。适量圆弧金属板、木质操作面、卷起的遮阳布、小旗和绑扎储物箱，增加手工感和生活气息。甲板仍然宽敞清楚，避免杂乱。远景岩石更圆润风化。不要蒸汽朋克齿轮、无用途管线或过多装饰。其他主要内容保持一致，便于比较整体风格。
```

# 水设施参考造型与实机接线

接续 `521901c`，以用户选定的 J 改善水设施外形。NW8 在 P1 的模型空间、保存兼容和支撑面机制上接入曲面储罐、独立检修舱和内凹饮水站；替换源模型不新增设施功能。功能和几何检查不代替实际画面验收。

## 本轮可检查计划

- [x] 在 Blender 制作一组水设施：有曲面端盖与支承的储罐、独立检修舱、折边机柜、内凹接水/操作面；保留真正的阀门、补水盖、检修盖和可见支撑区域。
- [x] 灰米结构、低饱和旧青绿、少量赭黄操作件和暖色指示灯组成材料层次。已查看离线形体与烘焙预览，输出颜色、法线与金属度/光滑度，保留活动分件。
- [x] 以独立 NW8 资产接入参考车辆，复用 P1 空间/动作绑定；原 P1 场景保留为回归基线。通过显式标记更新站位/支撑、校验轴向、网格与来源；空间变化继续执行已有保存拒绝规则，不静默改动旧存档。
- [x] 在同一实际光照和俯瞰镜头下检查造型、人物净空、取水/倾倒/维修，以及暂停、取消与恢复；完成相关导入和运行时验收，恢复非 Play 的参考车辆，整理阶段提交。

先以这一组代表设施确认可达到的造型和材质，再推广到厨房等设施。不新增设施能力，不通过临时改灯光掩盖模型问题；局部扩建、紧凑梯和两层携物继续承接主计划。离线 Blender 预览与 Unity 实机分别取证。

## 制作与接线

生成入口为 `Tools/ArtPipeline/Blender/blender_nomad_water_facilities.py`，当前配方 0.1.1，输出 `ArtPipelineOutput/WaterFacilities/v02`。`NW8_WaterFacilities_Source.blend` 保存原点未移位、未合并烘焙的编辑组件；`NW8_WaterFacilities.blend` 是错开摆放的烘焙预览，不能沿用预览位移直接重新导出。共享图集为三张 2048² PNG，活动件先记录所属枢轴、统一烘焙，再按顶点所属部件恢复独立网格。

Unity 菜单为“Assets/SSFramework/游牧工坊/首版美术/导入水设施并打开参考车辆”，入口 `NomadWaterFacilityArtPipeline`。它校核源脚本与交付文件哈希、FBX 往返/Unity 面数、Bounds、UV、独立轴标记；生成 NW8 的材质、Prefab 和定义。参考场景的 System 与 View 都连接新定义，回读确认持久引用，未改原 NW1 或 NW7 资产。

新水箱占地 1.8 × 1.2 m，维护托盘 0.50 × 0.38 m，支撑点位于设施局部 `(0.54, 1.28, 0.035)`；原 P1 托盘位于 `(0, 1.52, 0)`。FBX 的空节点保留 Blender 轴基，接线层在真实托盘节点下创建水平支撑 Frame，继续跟随模型位置；不旋转网格来满足支撑约束。EditMode 从实际烘焙网格读取三角形，在四个内部点检查朝上且同高的支撑面，避免把边框 Bounds 顶部误当桌面。

实际装水/倒水/维修近景暴露了单看端点一致性会遗漏的问题：入口过远、旧站位偏向罐体而非新机柜，以及顶板没有真正开孔。v02 将储罐补水口移至前肩，饮水站补水口移至顶板前部并开孔；维修位对准独立机柜，两组水操作位从入口左侧接近，保留共享水罐的身体净空。

共用姿态保留朝前的倾倒方向，按入口前后距离最多前伸 8 cm；入口接近肩部时平滑减少前伸，把臂长留给抬升。未增加固定动画或按设施 id 分支。初次 22 cm 前伸导致真实掌心脱离/前臂穿插，已由原接触阈值拦截；不能靠放宽接触标准接受更近的水流。新水流验收同时要求朝罐口前方、落点低于罐口至少 10 cm、水平距离不足 50 cm；这是本轮单手样板的检查范围，不声称任意入口都可达。更长距离应调整设施人体工学或补双手/躯干动作。

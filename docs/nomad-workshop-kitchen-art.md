# 小厨房造型与真实台面

接续 `789b5d7`，按 J 的清楚设备轮廓与用户要求的温暖感改善代表生活设施。当前厨房为 Unity/ProBuilder 原型，正面黑色面积大，俯视缺少灶具、水槽及生活层次。本阶段以 Blender 建模替换厨房外观，沿用既有设施身份、占地、工作组与杯具台面事务；烹饪尚无完整玩法，不制作虚假的持续炒菜动画。

## 可检查计划

- [x] 制作有折边的灰米机壳、旧青绿独立柜门、内凹水槽、灶具、木质备餐面和少量收纳；保留可编辑源组件和活动枢轴。
- [x] 烘焙共享颜色/法线/金属度与光滑度图集，检查 FBX 往返、UV、退化面及轴向。
- [x] 通过 Unity Editor 生成独立 NW9 Prefab/定义，绑定真实台面，接入现有参考车辆并保存回读；原厨房保留作为回归基线。
- [x] 在实际旋转/移动后验证杯具底部支撑、柜门分件和已有杯具搬运/暂停/检查点恢复；查看原光照俯瞰与厨房近景，完成相关回归并整理阶段提交。

台面 `countertop-center` 继续使用局部中心 `(0, .97, -.08)`、大小 `.42 × .42 m`；中间区域保持净空，水槽与灶具在两侧。装饰物不得被当作库存，也不得占用声明为可放物品的区域。柜门保留独立几何和枢轴，本阶段不新增按时循环的开门表演。新增资产是可替换表现，空间绑定由同一设施定义和模型标记生成。

S1/S2 仍按可扩建方案推进：车架与轮组保持有限挂点，板片并集减孔洞作为支撑；梯子先验证紧凑连接和真实携物，不能把旧长直梯直接放进车内。厨房作为固定米制设备，只需要保持独立根与功能空间，不把车体、上层或相邻家具焊入同一个网格。此阶段不提前批量制作墙板/梯子族。

## 制作与接线

脚本为 `Tools/ArtPipeline/Blender/blender_nomad_kitchen.py`，配方 0.1.1，当前输出为 `ArtPipelineOutput/Kitchen/v02`。`NW9_Kitchen_Source.blend` 保留未合并源组件，`NW9_Kitchen.blend` 为烘焙预览；两者均在本地输出目录，Unity 成品位于 `ArtFirstPass` 的 Models/Prefabs/Materials/Textures，制作配方与成品纳入 Git。

复用既有旧漆、金属和烘焙工具，新增木纹；一次生成共享 2048² 图集，再按顶点所属部件恢复静态外壳、台面、三扇门、锅身和锅盖，暖灯保持单独材质。最终为 16,808 三角形、8 个网格、退化面 0、完整 UV。首版自动贝塞尔把手超出占地约 5 cm，改用受控折线握把；毛巾属于左柜门，转门时一起移动。闭合状态全部可见网格位于原 2.1 × .95 m 占地内，未通过扩大导航障碍掩盖外观越界。

Editor 菜单为“Assets/SSFramework/游牧工坊/首版美术/导入小厨房并打开参考车辆”。来源哈希、导出往返、Unity 网格/材质/轴向先校核，再生成 NW9 自有 Prefab 和定义。功能台面引用实际木板节点，并建立跟随位置的水平 Frame；它与原厨房空间签名完全一致。初始朝向从 0° 改为 270°，使操作面朝甲板中央并在默认镜头中可见；已有检查点使用保存的实例朝向，不套用新开局方向。

## 本轮交付边界

本页记录的历史灰盒基线采用一条“旧营地—干河驿站”的 2 km 有限线段、10 m/s 恒速、初始燃料 20 L 和 2.5 L/km 油耗；首个单程纯行驶需 200 模拟秒。Foundation N0 已把正式路线调整为 8 m/s 巡航并加入 1.6 m/s² 加速、2.4 m/s² 制动，因此本页数值只用于复盘最初接线证据，不再作为当前平衡或运动契约。实际旅时还包含居民补水、如厕和休息；地点补给、车外作业和三居民原生移动的后续证据见 [Foundation §9](nomad-workshop-foundation-vertical-slice.md#9-下一步形成一次完整旅程)。

N0 后续接缝已允许以稳定路线锚点 ID 选择中途目的地；锚点复用端点方向、驾驶租约、加减速和到站语义，读档只保存 ID，实际进度由当前路线定义解析。Foundation 的 `midway-shelter` 已有 6/6 Journey PlayMode 证据；它不会打开干河驿站的资源权限。镜头缓冲已按实际 Moving 速度提供最多 0.45 m 的方向性偏移，并在暂停、读档和取消时收口；实机 Game View 截图已确认甲板逻辑位置不变，最终舒适度仍交给用户试玩。

玩家目标通过 Command 进入旅途 Session；相同目标幂等，改变或取消目标立即停车。驾驶作为现有 Utility 决策的候选，先记录目标版本，沿正式 NavMesh 路径到达驾驶台的 drive/seat，再同时持有交互空间与驾驶租约。运行 Harness 只能经同一 System 推进，不直接授予驾驶权。

需求持续推进。到岗要求口渴 <55%、膀胱压力 <65%、疲劳 <60%、健康 >30%；驾驶中口渴达到 75%、膀胱压力达到 90%、疲劳达到 80% 或健康降至 20% 就停车离岗。不同阈值避免在临界值来回走动；恢复条件必须通过真实生活行动满足。死亡、目标改变、空间失效、读取和销毁也会释放驾驶权。

v5 存档增加精确 Journey 记录：路线身份与参数、微米位置、皮升燃料、目的端点。宏观地图旧字段不被偷偷转换或丢弃；Foundation 拒绝非空旧地图状态。v4 及更早的合法甲板存档保留生活与设施真值，由 Foundation 在初始地点开启首次旅途。运行期租约不存档，读取后重新决策到岗。
